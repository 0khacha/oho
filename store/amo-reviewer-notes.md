# oho 0.1.1: notes for the AMO reviewer

oho has no remote code, makes no network requests, and collects no data.

## Source

`oho-source.zip` contains the extension's complete source, in TypeScript (`src/`). The code is
bundled and minified with esbuild. The build has no other inputs than the files in this zip and the
npm packages pinned in `package-lock.json`.

## Build environment

- Node.js **24.13.0**
- npm **11.6.2**
- Built and verified on Windows 11. The build scripts are plain Node.js, with no native tools,
  shell commands or network access.

## Build steps

```sh
unzip oho-source.zip -d oho && cd oho
npm ci
npm run build
```

The build writes the unpacked Firefox extension to `dist/firefox/`, and the same files zipped to
`oho-firefox.zip`, which is byte-identical to the uploaded package:

```
sha256(oho-firefox.zip) = 42cdf1a514418f1ba2f21b93885faf7eebf437ac88f0a8e9537b9cea629c4676
```

The zip is deterministic: fixed timestamps and a fixed file order (`scripts/zip.mjs`), and text
files are copied with LF line endings, so the result doesn't depend on the OS or Git's line-ending
settings.

## Where things are

| shipped file | source |
|---|---|
| `content.js` | `src/content.ts` + `src/rules.ts`, `src/candidates.ts`, `src/fallback.ts`, `src/features.ts`, `src/model.ts`, `src/walls.ts`, `src/shared/*`; rules from `rules/*.json`, model weights from `model/weights.json` |
| `api.js` | `src/api.ts` (runs in the page's MAIN world; calls only a fixed list of CMP reject functions) |
| `background.js` | `src/background.ts` (counters and per-site settings in `storage`) |
| `popup.js`, `popup.html`, `popup.css` | `src/popup/` |
| `manifest.json` | generated by `scripts/build.mjs` |
| `icons/*.png`, `icons/icon.svg` | rendered by `scripts/icon.mjs` / copied from `assets/mark.svg` |

`npx web-ext lint --source-dir dist/firefox` reports 0 errors, 0 warnings and 0 notices.
